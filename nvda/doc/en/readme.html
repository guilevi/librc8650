RC8650 (emulated)

An NVDA speech synthesizer that is an RC Systems RC8650 chip. Not a recreation of one: the chip's own firmware runs on an emulated Renesas M16C, and what you hear is the PCM its D/A converter would have produced. The voices, the text-to-speech and the command protocol are all the chip's.

The firmware image is RC Systems' copyrighted code and is not distributed with this add-on. Until you place one next to the driver, the synthesizer will not appear in NVDA's list. See the add-on's README for where it goes.

Voices

Eight, selected with the chip's own Voice command. Each one loads a preset inside the firmware, which is what gives it its character.

Settings

Selecting a voice snaps the settings below it in the list to that voice's firmware preset, so what the sliders say is what you hear. Move one and it overrides the preset for that voice; leave it alone and the preset comes through untouched.

SettingChip commandWhat it does
RatenS + nGTwenty steps, roughly 116 to 395 words per minute. The chip has two ten-step speed scales; this is both of them merged into one.
PitchnPThe chip's full 0–99 range.
InflectionnEHow much the pitch moves within a sentence. 0 is a monotone; the top is very animated.
VolumenV0–9, the chip's own.
TonenXBass, normal or treble.
ArticulationnALow slurs the speech, high makes it choppy.
Formant frequencynFShifts the whole vocal tract — retunes the voice type rather than its speed.
ReverbnR0 is dry; higher values lengthen it.
Word delaynTExtra pause between words. The datasheet suggests it for listeners new to synthetic speech.
PunctuationnBHow much punctuation the chip itself speaks: all, most, some, or none.
Read numbers as numbersnBOff reads 123 as "one two three" instead of "one hundred twenty three".
Speak leading zerosnBOn, "007" keeps its zeros. On a screen this is content, so it is on by default even though the chip's own default is off.
Read four-digit numbers as yearsnBOn, 1492 is "fourteen ninety-two".
Output filter—Not a chip command: the reconstruction filter on the modeled output stage. The RC8650's audio pins are unfiltered, and the datasheet's own reference circuit is a 3 kHz low-pass — the default here. "Off" is the bare 10 kHz staircase the pins themselves put out.

Known limitations

  • Index reporting is accurate to about a tenth of a second. NVDA's index marks are the chip's own index markers: the chip reports each one as it reaches that point in the text, and the driver announces the index when the audio around it plays. Speech is fed to the sound card in 102 millisecond chunks and an index is announced when its chunk has played, so a highlight can be up to that late — small enough not to be noticed while reading, but it is not sample-exact.
  • One instance per NVDA process. The emulator core keeps global state, so only one engine can exist at a time. Switching away and back is fine.
  • English only. The chip's Spanish support needs an exception dictionary that this driver does not load.
